# PWA Search

A modern Progressive Web App (PWA) search tool with Material Design and automatic light/dark theme support.

## Features

✨ **Modern Design**
- Material Design 3 styling
- Tea color theme (#8B6F47)
- Smooth transitions and animations

🌓 **Theme Support**
- Automatic light/dark mode based on system settings
- Seamless theme switching

📱 **PWA Capabilities**
- Installable on home screen (iOS & Android)
- Offline support via Service Worker
- Optimized for all devices
- Fast loading with caching strategy

🔍 **Quick Search**
- Search with multiple engines:
  - Google
  - V2EX
  - Z-Library
- Results open in new tab
- Enter key support

## Quick Start

1. Open `index.html` in a modern browser
2. Install as app (browser menu → "Install" or "Add to Home Screen")
3. Start searching!

## Files

- `index.html` - Main application with Material Design styles
- `manifest.json` - PWA manifest configuration
- `sw.js` - Service Worker for offline support
- `icon.png` - App icon (192x192 & 512x512)

## Browser Support

- Chrome/Edge 88+
- Firefox 85+
- Safari 14+
